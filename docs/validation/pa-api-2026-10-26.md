## Continuous-outcome behavior

The archived GPL-3 `pam.nlm()` body is retained as a test fixture, attributed
to Xiaoyan Wang and Gang Li. The new interface returns unrounded numeric
results; the supported old interface applies the historical four-decimal
character formatting to the same core result.

Tests independently cover hand-calculated values, the archived implementation,
the original Moore's Law example, joint row permutation, common-unit affine
transformation, retained precision, constant predictions, undefined
denominators, invalid vectors, missing/infinite inputs, overflow and underflow.
Integer vectors are converted to double before subtraction, so large finite
integers do not create an incidental integer-overflow warning.

A constant response leaves R-squared undefined. Zero original prediction
error leaves L-squared undefined. These produce NA for the affected measure
and a warning while retaining any other defined measure. These documented
rules intentionally replace historical incidental NaN/Inf behavior; complete
compatibility with all historical edge behavior is not claimed.

## Preservation and executable audit

The twelve before/after comparison groups cover simulations, Cox/AFT
prediction matrices, ordinary evaluation and calibration, CC/NCC weights,
two-phase evaluation, weighted calibration, competing-risk predictions,
competing-risk summaries and competing-risk calibration. All use exact
`identical()` comparisons with shared fitted-model inputs.

Snapshot test headings were renamed to match their test descriptions; all
serialized values are unchanged. The removed tests only exercised retired
alias wrappers. Existing estimator regression expectations were not changed.

The executable scientific audit now explicitly uses the PAmeasures namespace
for the internal R-squared helper, avoiding an unrelated installed TimeMetric
version. The isolated historical Cox source keeps its original git-object
path and adapts identifiers only inside its comparison environment.
